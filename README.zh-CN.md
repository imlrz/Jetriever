## 我们的前序工作

Jetriever 延续了我们在 **ReFind** 和 **InMind** 中展开的研究。阅读这两篇论文，可以帮助你理解本项目的研究动机。

### 🔎 ReFind

[![AML 学术文本赛道第2名](https://img.shields.io/badge/%E7%AC%AC%E4%B8%80%E5%B1%8A_Agent_Memory_Leaderboard-%E5%AD%A6%E6%9C%AF%E6%96%87%E6%9C%AC%E8%B5%9B%E9%81%93_%232-FFD700?style=flat-square)](https://agentmemories.ai/leaderboard/academic/textual)
[![论文](https://img.shields.io/badge/Paper-arXiv%3A2608.12888-b31b1b?style=flat-square)](https://arxiv.org/abs/2608.12888)
[![代码仓库](https://img.shields.io/badge/Code-GitHub-181717?style=flat-square&logo=github)](https://github.com/imlrz/ReFind)

**When Your Agent Opens the Chat App: Agent-Controlled Search over Raw Chat Logs Rivals Structured Memory**

ReFind 研究 Agent 如何主动搜索原始聊天记录，并将其作为检索预结构化记忆的替代方案。该系统获得了**第一届 Agent Memory Leaderboard 学术文本赛道第2名**。

### 🧠 InMind

[![论文](https://img.shields.io/badge/Paper-arXiv%3A2607.24368-b31b1b?style=flat-square)](https://arxiv.org/abs/2607.24368)
[![代码仓库](https://img.shields.io/badge/Code-GitHub-181717?style=flat-square&logo=github)](https://github.com/imlrz/InMind)
[![评测集](https://img.shields.io/badge/Benchmark-125_Tasks-4c78a8?style=flat-square)](https://keep-it-inmind.github.io/)

**Keep It InMind: Benchmarking the Implicit-Association Blind Spot in Agent Memory**

InMind 评测这样一类场景：一条历史事实与当前问题的联系依赖隐含的世界知识，而非表面文本相似性。

---

ReFind、InMind 与 Jetriever 是一脉相承的 Agent Memory 研究。阅读这两篇论文，可以帮助你理解 Jetriever 的研究动机，以及它在我们整体研究脉络中的位置。

在我们完成 Jetriever 的整理之前，你可以先阅读 ReFind 和 InMind。感谢你的关注，更多内容即将在这里发布，敬请期待。
