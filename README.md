**Jetriever** is an agent-memory retrieval system that uses Jev to score the relevance of stored interactions to a query.

We will soon release the Jetriever code and technical report. If you are interested in the project, please star this repository and stay tuned.

## While you wait

You may also be interested in our earlier work, **ReFind** and **InMind**:

### 🔎 ReFind

**When Your Agent Opens the Chat App: Agent-Controlled Search over Raw Chat Logs Rivals Structured Memory**

ReFind studies agent-controlled search over raw chat logs as an alternative to retrieving from pre-structured memories.

[Read the paper](https://arxiv.org/abs/2608.12888) · [Explore the repository](https://github.com/imlrz/ReFind)

### 🧠 InMind

**Keep It InMind: Benchmarking the Implicit-Association Blind Spot in Agent Memory**

InMind evaluates whether a memory system can retrieve a past fact when its relevance to the current query depends on an implicit world-knowledge association.

[Read the paper](https://arxiv.org/abs/2607.24368) · [Explore the repository](https://github.com/imlrz/InMind)

ReFind, InMind, and Jetriever form a continuous line of work on agent memory. Reading these two papers will provide the background needed to understand the motivation behind Jetriever and how the project fits into our broader research.

While we finish preparing Jetriever, we invite you to start with ReFind and InMind. Thank you for your interest—more will be available here soon.
