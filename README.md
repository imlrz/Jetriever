## Our previous work

Jetriever continues a line of research developed through **ReFind** and **InMind**. These two papers provide useful context for the motivation behind this project.

### 🔎 ReFind

[![AML Academic Textual #2](https://img.shields.io/badge/1st_Agent_Memory_Leaderboard-Academic_Textual_%232-FFD700?style=flat-square)](https://agentmemories.ai/leaderboard/academic/textual)
[![Paper](https://img.shields.io/badge/Paper-arXiv%3A2608.12888-b31b1b?style=flat-square)](https://arxiv.org/abs/2608.12888)
[![Repository](https://img.shields.io/badge/Code-GitHub-181717?style=flat-square&logo=github)](https://github.com/imlrz/ReFind)

**When Your Agent Opens the Chat App: Agent-Controlled Search over Raw Chat Logs Rivals Structured Memory**

ReFind studies agent-controlled search over raw chat logs as an alternative to retrieving from pre-structured memories. It ranked **second on the Academic Textual Track of the first Agent Memory Leaderboard competition**.

### 🧠 InMind

[![Paper](https://img.shields.io/badge/Paper-arXiv%3A2607.24368-b31b1b?style=flat-square)](https://arxiv.org/abs/2607.24368)
[![Repository](https://img.shields.io/badge/Code-GitHub-181717?style=flat-square&logo=github)](https://github.com/imlrz/InMind)
[![Benchmark](https://img.shields.io/badge/Benchmark-125_Tasks-4c78a8?style=flat-square)](https://keep-it-inmind.github.io/)

**Keep It InMind: Benchmarking the Implicit-Association Blind Spot in Agent Memory**

InMind evaluates whether a memory system can retrieve a past fact when its relevance to the current query depends on an implicit world-knowledge association.

---

ReFind, InMind, and Jetriever form a continuous line of work on agent memory. Reading these two papers will make it easier to understand Jetriever's motivation and its place in our broader research.

While we finish preparing Jetriever, we invite you to start with ReFind and InMind. Thank you for your interest—more will be available here soon.
